# Безопасность / Security

Если нашли уязвимость (обход входа в админку, чужие ключи, подделка оплаты и т. п.), не открывайте публичную заявку. Напишите через [Security advisory](https://github.com/WWS909/vpn-seller/security/advisories/new) — её видит только автор. Опишите, как повторить, и что можно получить. Ответ — в течение нескольких дней; после исправления вас упомянут в «Что нового», если захотите.

Поддерживается последняя версия: магазин обновляется одной кнопкой (админка → «Обновления» или `vpn-seller` → «Обновить до новой версии»).

---

Found a vulnerability (admin login bypass, access to other people's keys, forged payments, etc.)? Please do not open a public issue. Report it privately through a [security advisory](https://github.com/WWS909/vpn-seller/security/advisories/new) with steps to reproduce and the impact. Only the latest version is supported; shops update with one button.
