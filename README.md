Большинство открытых проектов для продажи VPN-ключей — это чат-боты с кнопками. VPN Seller — полноценное приложение внутри Telegram: пользователь открывает его из бота, выбирает тариф, платит и подключает устройство в пару нажатий. Ключи выдаются на ваших серверах с [3x-ui](https://github.com/MHSanaei/3x-ui), [Marzban](https://github.com/Gozargah/Marzban) или [Remnawave](https://github.com/remnawave/panel), а всем управляете из веб-админки или прямо из бота.

> **Посмотреть вживую.** Откройте [@Cristal_vpn_app](https://t.me/Cristal_vpn_app) и нажмите «Открыть» — это магазин, который работает на VPN Seller. Так приложение выглядит у покупателя: главная, тарифы, оплата, подключение, поддержка.

```bash
wget -qO install.sh https://raw.githubusercontent.com/WWS909/vpn-seller/main/install.sh && sudo bash install.sh
```

### Чем отличается от бота с кнопками

| | Обычный бот | VPN Seller |
|---|---|---|
| Что видит покупатель | сообщения и кнопки | приложение: экраны, остаток дней и трафика, устройства, локации |
| Подключение | ключ текстом в чат | одна ссылка-подписка на все серверы, добавление в Happ, v2RayTun и другие в одно нажатие, QR |
| Оплата | обычно одна касса | Telegram Stars, карты, СБП и крипта — 15 платёжных систем на выбор, баланс и рефералы |
| Управление | команды в боте | веб-админка с графиками и та же панель внутри Telegram |
| Оформление | — | 3 вида главного экрана и 6 стилей, свой цвет, логотип, 30 шрифтов, 13 видов иконок, заставка |
| Установка и обновление | вручную | одна команда, мастер на русском, новая версия с GitHub одной кнопкой |

## Возможности

**Для пользователя**
- Главная с остатком дней, трафиком и устройствами, список локаций, управление устройствами.
- Тарифы с ценой в месяц, скидкой и бейджем, пробный период (один раз на аккаунт), промокоды.
- Одна ссылка-подписка на все серверы сразу; добавление в одно нажатие в Happ, v2RayTun, Incy, OneXray, Karing или Hiddify (владелец выбирает, какие показывать и какое первым), QR-код, сброс ссылки.
- Докупка устройств и пакетов трафика, подарочные подписки по ссылке `t.me/<бот>?start=gift…`.
- **Чат с поддержкой** прямо в приложении и в боте, ответы приходят в тот же чат.
- Отзывы, FAQ, страница «О сервисе».
- Русский и английский (по языку Telegram, можно переключить), тёмная и светлая тема.

**Для владельца**
- **Чистый старт**: после установки магазин пустой — ни тарифов, ни скидок, ни документов, реферальная программа выключена. Ничего не продаётся и не раздаётся без вашего решения; для тарифов, документов и частых вопросов есть шаблоны, которые вы правите перед сохранением.
- **Вкладка «Запуск»**: обязательные шаги (бот, сервер, тарифы, оплата, документы, проверка как клиент) и рекомендуемые (название, логотип, пробный период, продавец, описание бота, свои вопросы, рефералка, прогрев, домен, бэкапы). Галочки ставятся только по факту.
- Админ-панель: обзор с выручкой и проблемами, **аналитика** (воронка «пришли → открыли → пробный → подключились → оплатили → продлили», выручка по способам оплаты и тарифам, отток, LTV), заказы, тарифы, промокоды, подарки, пользователи, рассылки, отзывы, серверы, оформление, настройки, журнал. Работает и на телефоне.
- **Управление из Telegram**: команды и кнопки в самом боте, а вся панель открывается внутри Telegram без пароля — админа узнаёт подпись Telegram.
- **Своё оформление**: собирается из деталей — логотип, цвет, фон, шрифт, иконки, карточки, анимации, заставка; готовых тем нет. Цвета текста подбираются автоматически, чтобы оставаться читаемыми.
- **Пробный период**: сколько дней, устройств и трафика — одной карточкой в «Тарифах» или командой `/trial 7`.
- **Прогрев клиентов**: распродажа на все тарифы, системные уведомления (подписка заканчивается, закончилась, пробный на исходе, не купил после входа, трафик на исходе) и свои кампании по сегментам. Всё со скидками выключено, пока вы не включите.
- **Рефералы на выбор**: дни подписки или деньги — процент с оплат друзей на баланс. Баланс выводится по заявке (карта, СБП, крипта — способы задаёте вы, заявку закрываете в панели или кнопкой в боте) или тратится на свою подписку. Капча против накрутки, топ рефоводов.
- **Обязательная подписка на каналы** — один или несколько (до пяти), для всего сервиса или только для пробного периода.
- **Поддержка в боте**: вопросы клиентов приходят админам с карточкой клиента, ответ — реплаем в боте или из панели; клиент получает его от имени бота.
- **Источники**: своя ссылка на бота для каждого ролика, блогера или рекламы — видно, сколько людей пришло, сколько оплатило, сколько денег принесли и окупилась ли реклама.
- **Проверка самого VPN**: магазин каждые 2 минуты проверяет порт подключения из ключей; сервер с упавшим VPN временно убирается из подписок, админам приходит сообщение.
- **Продление в один тап**: напоминание об окончании подписки приходит со счётом в звёздах на тот же тариф.
- **Нагрузка серверов** в «Локациях»: свободно / средне / загружен — по числу людей онлайн на панели.
- **Ускорение VPN-сервера** одной командой (`tune.sh`): BBR, большие сетевые буферы, лимиты.
- **Панели 3x-ui (2.x и 3.x), Marzban и Remnawave** — сколько угодно серверов и можно вперемешку: клиент получает одну подписку со всех. Проверка подключения и выбор инбаундов прямо в форме.
- **Итоги дня в Telegram** каждый вечер (выручка, покупки, новые люди, что требует внимания), **выгрузка заказов и клиентов в Excel**, напоминание о **брошенной оплате**.
- **Обновления из GitHub**: магазин сам находит новую версию, присылает в Telegram «что нового» и обновляется одной кнопкой (в боте или в админке). Перед обновлением — копия базы; если новая версия не запустилась, прежняя возвращается сама. Можно включить автообновление ночью.
- **Установка одной командой**: скрипт ставит Docker, спрашивает домен, токен и пароль, получает сертификат и запускает; он же обновляет, делает бэкап и восстанавливает.
- **Доступ после окончания**: владелец задаёт, сколько дней VPN ещё работает после окончания подписки (0–30, по умолчанию 0). Клиент видит в приложении «N дней до отключения» и дату, VPN-приложение — строку «VPN работает до …». На пробный период не действует; продление считается от конца оплаченного срока или от сегодня, эти дни не продаются.
- **Режим аварии**: одной кнопкой (или `/emergency on текст` в боте) — сообщение всем клиентам вверху приложения и после /start, остановка продаж и пробных периодов (уже оплаченное выдаётся как обычно, напоминания со скидками ждут) и, по желанию, «никого не отключать», пока режим включён.
- **Только Telegram после окончания**: когда VPN отключился, ещё N часов (выбирает владелец) работает только Telegram — чтобы человек зашёл в бот и продлил. Для этого на сервере делается отдельный инбаунд (в Remnawave — сквад), где маршрутизация пускает только Telegram; магазин кладёт туда отдельного клиента, настоящий клиент остаётся выключенным.
- **Режим аварии сам**: если панели или VPN всех серверов не отвечают дольше заданного, режим включается сам и сам выключается, когда сервер ожил. Включённый владельцем режим сам не выключается.
- **Доступность из России**: свой бесплатный проверяльщик (`scripts/ru-probe.py`, ставится одной командой на любой российский VPS, можно несколько — по городам и операторам) каждые 5 минут подключается к серверам как VPN-приложение и сообщает, если оператор их режет. Плюс платная проверка из десятков регионов через DPI Checker (`DPICHECKER_API_KEY`) — с показом цены до запуска.
- **Чёрные списки**: подписка на списки Telegram ID других магазинов (кто фармит пробные, делает возвраты) — не давать пробный или не продавать вовсе; можно делиться своим списком по адресу `/blacklist.txt`.
- **Команда**: помощники по Telegram ID с выбранными разделами (обзор, продажи, клиенты, поддержка, система). Права проверяет сервер на каждом запросе; вопросы поддержки в боте приходят и им.
- **Диагностика**: раздел «Авария» в панели и `/diag` в боте проверяют по-настоящему базу, бота и вебхук, сертификат сайта, каждую панель, VPN на серверах, оплаты и зависшие платежи, фоновые задачи, бэкапы и место на диске — и подсказывают, что сделать.
- **Оповещение о входе в панель**: если в админку вошли по паролю с нового адреса, админам сразу приходит сообщение в Telegram с адресом и устройством (Chrome · Windows и т. п.). Если кто-то подбирает пароль — тоже сообщение, один раз, в момент когда адрес закрывается.
- **Автобэкап**: каждый день архив базы приходит админам в Telegram; плюс кнопка в панели и команда `/backup`.
- Серверы «обход белых списков» для мобильного интернета: их трафик продаётся гигабайтами (в тарифе и пакетами), без гигабайтов сервер не выдаётся, закончились — отключается только он.
- Кассы и ключи оплаты настраиваются прямо в админке (раздел «Оплата»), без терминала; ключи из .env тоже работают.
- Лимит устройств по HWID (Happ, v2RayTun, Incy и другие клиенты с заголовком `X-HWID`), лимит трафика с блокировкой; докупка трафика — по желанию (Настройки → «Докупка трафика», изначально выключена).
- Отвязанное устройство больше не получает подписку, пока клиент сам его не вернёт; неистраченный докупленный трафик переносится при продлении.
- Новая ссылка выдаётся, только если её принял хотя бы один сервер; в Remnawave при сбросе ссылки и отключении открытые соединения обрываются сразу.
- Если сервер недоступен, покупка всё равно проходит на остальных, а пропущенный сервер догоняется фоновой задачей. Оплаченный заказ никогда не теряется: при сбое всех серверов он ждёт и выдаётся автоматически.
- Уведомления в Telegram о каждой оплате и падении серверов.
- Публичная страница сервиса с ценами, контактами и вашими документами — соглашением и политикой конфиденциальности (нужна платёжным системам для модерации). Документы пишутся во вкладке «Документы», можно начать с шаблона.

## Как это устроено

```mermaid
flowchart LR
    U["Покупатель<br/>в Telegram"] -->|открывает| APP["Мини-приложение<br/>/app"]
    U -->|пишет| BOT["Бот<br/>вебхук"]
    O["Владелец"] --> ADM["Админка<br/>/admin и в боте"]
    APP --> VS(("VPN Seller<br/>FastAPI · SQLite/PostgreSQL"))
    BOT --> VS
    ADM --> VS
    PAY["Кассы<br/>Stars · карты · СБП · крипта"] -->|уведомление об оплате| VS
    VS -->|создаёт и продлевает клиентов| P["Панели<br/>3x-ui · Marzban · Remnawave"]
    VPN["VPN-клиент<br/>Happ, v2RayTun…"] -->|/sub/…| VS
```

Отдельного процесса бота нет: Telegram присылает обновления на вебхук сервиса. При старте сервис сам регистрирует вебхук, кнопку меню и команду `/start`.

Каждый покупатель становится клиентом `tg<telegram id>` во всех включённых серверах. Сервис раздаёт собственную ссылку подписки: собирает ключи со всех панелей, подписывает их флагом и названием сервера и добавляет в заголовки остаток трафика и срок. Когда подписка закончилась или превышен лимит устройств, клиент получает понятное сообщение вместо ключей.

## Быстрый старт

Нужны: VPS на Ubuntu или Debian (от 1 ГБ памяти), бот от [@BotFather](https://t.me/BotFather) (`/newbot`) и панель 3x-ui, Marzban или Remnawave — её можно добавить и после установки. Домен желателен, но не обязателен: без него установщик даст временный адрес Cloudflare, чтобы попробовать.

**Одной командой** (от root):

```bash
wget -qO install.sh https://raw.githubusercontent.com/WWS909/vpn-seller/main/install.sh && sudo bash install.sh
```

или `curl -fsSL https://raw.githubusercontent.com/WWS909/vpn-seller/main/install.sh | sudo bash`.

Откроется меню, затем пять вопросов прямо в терминале:

1. **Токен бота** — сразу проверяется в Telegram.
2. **Ваш Telegram ID** — установщик может узнать его сам: вы пишете боту любое сообщение.
3. **Адрес** — свой домен или временный адрес Cloudflare.
4. **Пароль админки** — Enter, и установщик придумает надёжный.
5. **Валюта** цен.

Дальше всё само: Docker, код, `.env` (права 600), HTTPS, запуск, подключение бота (вебхук и кнопка «Открыть»). В конце — адрес админки, пароль и что делать дальше.

**Если порты 80/443 уже заняты** другим проектом, установщик разбирается сам:

| Кто занял порты | Что делает установщик |
|---|---|
| никто | ставит свой Caddy, сертификат выпускается автоматически |
| Caddy другого проекта в Docker | подключает магазин к его сети, дописывает блок сайта в его Caddyfile (перед этим — копия, `caddy validate`, при ошибке возвращает как было), перезагружает Caddy без остановки |
| nginx, Traefik и т.п. в Docker | подключает магазин к его сети и показывает, что вписать в его настройки |
| nginx или Caddy прямо на сервере | магазин слушает только `127.0.0.1:8080` (снаружи недоступен), установщик показывает готовый блок для nginx |

Магазин никогда не открывается наружу напрямую, в обход прокси: иначе защиту от перебора пароля админки можно было бы обойти подделкой IP.

**Временный адрес Cloudflare** (без домена) меняется при перезапуске сервера. Магазин сам замечает новый адрес и перенастраивает бота, но ссылки подписок, уже выданные клиентам, перестанут обновляться — для продаж подключите домен: `vpn-seller` → «Сменить адрес».

## Проверка VPN и автоскрытие

Панель может отвечать, когда сам VPN лёг, и наоборот. Поэтому магазин запоминает из ключей, по какому адресу и порту клиенты подключаются к каждому серверу, и каждые 2 минуты открывает туда соединение. Три неудачи подряд (около 6 минут — короткий сбой не считается) — сервер временно убирается из подписок, VPN-приложения перестают предлагать мёртвый сервер, админам приходит сообщение. Ответит — вернётся сам. Если не отвечает ни один сервер, не убирается никто (скорее проблема у самого магазина). UDP-протоколы (Hysteria, TUIC, WireGuard, mKCP) так не проверить — они не учитываются. Выключается в «Настройках».

## Продление в один тап

Напоминание «подписка заканчивается» (и «закончилась», если включено) приходит сразу со счётом Telegram Stars на тот же тариф с тем же числом устройств и положенной скидкой. Кнопка «Оплатить ⭐» — и подписка продлена, приложение открывать не нужно. Рядом кнопка «Другие способы оплаты». Выключается в «Настройках».

## Нагрузка серверов

Каждые 2 минуты магазин спрашивает у панелей, сколько людей онлайн (3x-ui, Marzban и Remnawave это отдают), и показывает в «Локациях» метку: свободно / средне / загружен. Порог задаётся полем «Рассчитан на, человек онлайн» у сервера (по умолчанию 200). Если панель давно не отвечала, метки нет — никаких догадок. Выключается в «Настройках».

## Ускорение сервера

```bash
curl -fsSL https://ваш-магазин/scripts/tune.sh -o tune.sh && sudo bash tune.sh
```

Включает BBR и очередь fq, увеличивает сетевые буферы до 16 МБ, очереди соединений, MTU probing, TCP Fast Open и лимит открытых файлов до миллиона. Показывает значения до и после. Ничего не меняет в панели и Xray. Выполняйте на VPN-серверах; `bash tune.sh --undo` — убрать.

## Серверы Marzban

Поддерживается Marzban 0.8.x (проверено на 0.8.4). В форме сервера выберите «Marzban»:

- **Адрес** — тот, по которому открывается дашборд, например `https://host:8000/` (`/dashboard/` в конце можно оставить — отрежется).
- **Логин и пароль** администратора Marzban с правами sudo (`marzban cli admin create --sudo`). API-токен и адрес подписки не нужны: ссылки Marzban отдаёт сам.
- **Инбаунды** — теги через запятую (`VLESS TCP REALITY, Shadowsocks TCP`); «Проверить» покажет список.
- Клиент в Marzban — пользователь `tg<id>` с протоколами выбранных инбаундов, сроком, лимитом трафика и статусом. Блокировка и конец подписки делают его `disabled`, «Новая ссылка» меняет ключи.

## Серверы Remnawave

Поддерживается Remnawave 2.x и 3.x (API проверен по контракту 3.4). В форме сервера выберите «Remnawave»:

- **Адрес** — тот, по которому открывается панель, например `https://panel.example.com/`.
- **API-токен** — Remnawave → API-токены → Создать. Без токена можно указать логин и пароль администратора.
- **Внутренние сквады** — через какие сквады клиент получает доступ; «Проверить» покажет список с названиями.
- Клиент в Remnawave — пользователь `tg<id>` с Telegram ID, сроком, лимитом трафика и выбранными сквадами. Блокировка и конец подписки делают его `DISABLED`, «Новая ссылка» перевыпускает ключи (старые ссылки перестают работать, счётчик трафика сохраняется).
- Remnawave принимает запросы только через обратный прокси с HTTPS. Если магазин обращается к панели напрямую (тот же сервер или Docker-сеть, `http://remnawave:3000/`), он сам добавляет заголовки `X-Forwarded-Proto: https` и `X-Forwarded-For` — ничего настраивать не нужно.

Серверы 3x-ui, Marzban и Remnawave можно смешивать: в подписке клиента будут ключи со всех.

Одна панель — один сервер в магазине: панель хранит одного пользователя на клиента, и две записи с одним адресом перезаписывали бы друг друга (магазин такое не сохранит). Если у панели Remnawave или Marzban несколько нод в разных странах, добавьте её один раз и отметьте нужные сквады/инбаунды; назовите хосты в самой панели с флагом в начале («🇩🇪 Франкфурт») — эти названия останутся в подписке.

Если ни одна панель не отвечает (перезапуск, сбой), подписка отвечает ошибкой 503, а не пустым списком: VPN-приложения клиентов сохраняют рабочие ключи, пока панель не вернётся.

## Поддержка в боте

Всё, что клиент пишет боту (кроме команд), и вопросы из раздела «Поддержка» в приложении приходят всем админам из `ADMIN_TELEGRAM_IDS` — с именем, ID, сроком подписки и кнопкой «Карточка клиента». Фото, файлы и голосовые пересылаются как есть. Чтобы ответить, достаточно **ответить (reply) на это сообщение** в боте — клиент получит ответ от имени бота и увидит его в приложении. Вся переписка видна в панели → «Поддержка», оттуда тоже можно ответить; ждущие ответа отмечены и видны в меню бота `/admin`.

Выключается в «Настройки» → «Чат поддержки в боте» (тогда кнопка «Поддержка» ведёт на контакт из настроек). Защита от флуда — 20 сообщений в час.

### Чеки «Мой налог» (самозанятые)

Если указать ИНН и пароль от lknpd.nalog.ru (`vpn-seller` → «Способы оплаты» → «Мой налог», или `NALOG_INN` и `NALOG_PASSWORD` в `.env`), после каждой оплаты через FreeKassa, Platega, PayPalych, Lava или WATA магазин сам создаёт чек. ЮKassa для самозанятых отправляет чеки сама, поэтому её в списке нет; список меняется в `NALOG_GATEWAYS`.

- По каждому заказу — не больше одного чека: запись о чеке появляется в базе до отправки.
- Если «Мой налог» недоступен, чек ждёт и отправляется позже.
- Если ответ не пришёл (чек мог создаться), магазин **не** отправляет его снова, а пишет администратору. В админке → Заказы → Чеки отметьте, есть ли чек в приложении «Мой налог».
- Возвраты и аннулирование чеков делаются вручную в приложении «Мой налог».

Для модерации кассы обычно просят сайт с описанием услуги, ценами и контактами — это главная страница `https://DOMAIN/`. Заполните в настройках «Исполнитель» и «Почта для обращений». Файлы подтверждения домена (`xxxx.txt`) положите в `data/verify/` — они будут доступны по адресу `https://DOMAIN/xxxx.txt`.

| `/broadcast Текст` | Рассылка; кому — выбирается кнопкой (всем, с подпиской, с закончившейся, не покупавшим) |

Всё, что сделано из бота, попадает в журнал панели с вашим Telegram ID.

Любая деталь сочетается с любой — например, пиксельные иконки на зимнем фоне. Ниже — особые детали; включайте их по одной или вместе.

Шкала трафика — полоска здоровья из блоков, у главной карточки и шторок — бегущая полосатая «вывеска». Всё движется кадрами: экран «прорисовывается» сверху вниз, иконки выскакивают по очереди, монета крутится, звезда мигает, курсор меню прыгает к вкладке. Светлая тема — кремовая бумага и чёрная тушь. Заголовки и цифры написаны жирным курсивом Rubik с чёрным контуром и красной тенью, текст — Balsamiq Sans, как буквы в облачках. Иконки — свой набор цветных «наклеек» с точечной тенью и белой каймой. На заставке приземляется звезда-взрыв, а при покупке — взрыв с галочкой и надпись «БАЦ!» (в английском — «BAM!»). Днём — кремовая бумага, ночью — тёмный «нуар-выпуск». Наклейки, панели «Комикс» и фон «Комикс-точки» включаются и по отдельности.

Карточки — матовое стекло, сквозь которое видно небо, на главной карточке, плитках и меню лежат сугробы. Иконки — нарисованные новогодние вещи: пряничный домик, снежный шар, снеговик, носок для подарков, снегирь, подарок, бенгальский огонь; некоторые оживают (подарок покачивается, звезда искрится). Заголовки и цифры — жирные круглые буквы, белые как снег, с красной карамельной кромкой. На заставке качается красный шар на фоне сияния, полоска загрузки — карамельная трость, при покупке — шар с галочкой и салют. Днём — снежное утро.
- **Китайский Новый год** (иконки «Красные ромбы», карточки «Лак и золото», фон «Фонарики», шрифт Yeseva One) — красный лак и золото: узор облаков, два фонарика качаются вверху, карточки в золотой рамке с уголками-«меандром». Главная карточка — красный конверт «хунбао» с клапаном и золотой монетой, иконки — красные ромбы с золотом, как праздничные украшения на дверях, они поворачиваются при появлении и поблёскивают. Заголовки — Yeseva One, цифры — золотом, на заставке фонарь, при покупке — красный ромб с золотой галочкой и салют. Днём — рисовая бумага, акцент становится красным (золото на белом не читается), конверт остаётся красным.
- **Главный экран** — с чего начинается приложение. «Ответ»: сверху фраза «Работает до 26 декабря», под ней одна главная кнопка и короткий список — устройства, страны, продление. «Срок»: календарь до конца подписки и продление прямо на экране — человек выбирает срок и видит, до какого числа продлит. «Устройства»: подключённые устройства (телефон, ноутбук, телевизор — по тому, что сообщает приложение), свободные места и кнопка «Подключить ещё одно». «Классика» — карточка с днями и две плитки. Когда подписка заканчивается, закончилась или кончился трафик, на каждом экране меняется текст и главная кнопка.
- **Стиль** — «Чистый»: светло-серый фон и белые группы, как списки Telegram; один цвет только на кнопках, без подписей капсом, точек после заголовков и свечения. «Мягкий» — по Material, как в Android: фон в оттенке цвета магазина, круглые кнопки, подсветка выбранной вкладки. «Фирменный» — шапка в цвет магазина, как в приложениях банков (Telegram красит свою шапку так же). «Крупный» — крупный текст, высокий контраст, большие кнопки и чёткие рамки, легко читать. «Космос» — как на сайтах VPN: ночной фон с подсветкой цветом магазина, стеклянные карточки, крупные цены с градиентом, у самого выгодного тарифа лента «Лучший выбор». Все пять светлые и тёмные вслед за Telegram; при их выборе шрифт заголовков сам меняется на Golos (можно поменять). «Тёмная классика» — тёмные карточки, свои фоны, карточки и особые наборы (настройки «Фон» и «Карточки» работают в ней).
- **Название и логотип** — PNG, JPEG, WebP или SVG до 2 МБ. Логотип появляется в шапке приложения, на заставке при открытии, в панели, на сайте и во вкладке браузера. Аватарку самого бота меняет только @BotFather (`/setuserpic`) — логотип можно скачать тут же.
- **Цвет** — любой акцент (пипетка или #код) и фон тёмной темы (чёрный, графит, полночь, индиго, ретро, нуар, зима, красный лак). Если цвет плохо читается, сервис сам затемнит или осветлит его для текста — в обеих темах. Цветные кружки под пипеткой — только быстрый выбор: они заполняют акцент и фон.
- **Шрифт** — 30 пар с кириллицей в четырёх группах: простые (Manrope, Montserrat, Rubik, Nunito, Onest, Geologica, PT Sans, IBM Plex Sans, Fira Sans, Ubuntu, Jost, Commissioner, системный), с засечками (Playfair, PT Serif, Lora, Literata, Roboto Slab), с характером (Unbounded, JetBrains Mono, Exo 2, Comfortaa, Oswald, Russo One, Tektur, IBM Plex Mono) и для особых оформлений (пиксели, комикс, Новый год). Можно вписать **любой шрифт с Google Fonts** — он возьмёт заголовки и цифры, текст останется в Golos; панель сразу проверит, что такой шрифт есть и в нём есть кириллица. **Скругление углов** (строгое, обычное, мягкое — ему следуют все кнопки, поля и карточки) и **иконки** — тонкие, обычные, жирные, в плашках цвета темы, **цветные плашки** (белый рисунок на квадрате своего цвета, как в настройках телефона: деньги зелёные, подарки розовые, помощь бирюзовая), **в кружках**, переливы и особые наборы ниже.
- **Фон** — сияние, переливы, сетка, звёзды или без фона; всегда в тон цвета, без вторых цветов.
- **Анимации** — «живые» (заставка с логотипом, поставленное появление экрана, переходы между вкладками, подсветка меню, которая переезжает к вкладке, счётчик дней, празднование покупки), «спокойные» (только мягкие проявления) или без анимации. У людей с системной настройкой «уменьшить движение» анимаций нет всегда.
- **Заставка при открытии** — логотип, название и своя строка, пока приложение загружается. Семь видов на выбор: «Под оформление» (у карточек «Пиксели», «Комикс», «Снежные» и «Лак и золото» — свои), «Волны» (от знака расходятся круги), «Орбита» (вокруг знака бегут точки), «Кольцо» (знак в бегущем кольце загрузки), «Вспышка» (знак вылетает со вспышкой и искрами, буквы съезжаются), «Печать» (название печатается по буквам с курсором) и «Минимум» (только название и тонкая линия) — или без заставки. Каждый вид берёт ваши цвета и шрифт. В панели у каждого вида живая миниатюра, а выбранный сразу проигрывается в телефоне. Заставка **подстраивается под логотип**: при загрузке он разбирается — где сам рисунок (прозрачные поля обрезаются), какие у него пропорции, есть ли прозрачность, светлый он или тёмный и какой у него основной цвет. Широкий логотип-надпись получает широкий знак, а волны и кольцо идут по его форме; название рядом с таким логотипом в режиме «Авто» скрыто — оно уже в логотипе. Фото или иконка без прозрачности — со скруглёнными углами; тёмный логотип на тёмной теме — на светлой подложке. Длинное название уменьшается, чтобы встать в одну строку. Настройки: знак (логотип, первая буква названия или щит), подложка (авто, плитка, круг, без), размер, цвет (акцент, **из логотипа** или свой), фон (обычный, свечение или **заливка цветом** — экран бренда), показывать ли название и сколько держится заставка. В строку можно вставить `{name}` — там будет имя человека из Telegram («Привет, {name}!»). **Сезонный эффект** — лёгкий снег за карточками.
- **Бот в Telegram** — короткое описание и описание «Что умеет этот бот?» на русском и английском; уходят в Telegram сразу при сохранении.
- **Тема по умолчанию**, **строка на главной** и **свои кнопки** в профиле клиента (до шести).

Всё это попадает в страницу ещё на сервере, поэтому при открытии не мелькает тема по умолчанию.

## Прогрев клиентов

Админка → «Прогрев».

**Распродажа** — скидка на все тарифы для всех (до 90%), на N дней или до выключения, со своим названием. В приложении появляется плашка и зачёркнутые цены. Команда в боте: `/sale 25 3`.

**Системные уведомления** срабатывают сами, каждое — один раз на событие:

| Уведомление | Когда | После установки | Скидка, если включить |
|---|---|---|---|
| Подписка скоро закончится | за 2 дня до конца | включено | — |
| Заканчивается пробный период | за 1 день | выключено | 20% на 3 дня |
| Подписка закончилась | через 1 день | выключено | 15% на 3 дня |
| Вернуть ушедших | через 14 дней | выключено | 25% на 5 дней |
| Не подключился после входа | через 24 часа | выключено | 10% на 3 дня |
| Брошенная оплата — начал платить и не закончил | через 60 минут | включено | — (одно напоминание, кнопка «Завершить оплату») |
| Трафик на исходе | при 80% | включено | — |

Уведомления со скидкой после установки выключены — никто не получит скидку, пока вы сами её не включите.

У каждого можно поменять срок, скидку, время действия скидки и текст (RU/EN, с подстановками `{name}`, `{percent}`, `{until}` и другими) и прислать пример себе в Telegram.

**Кампании** — ваши рассылки со скидкой: сегмент (все, ни разу не подключались, брали пробный и не платили, не платили, активные, заканчивается за неделю, закончилась), текст, процент, сколько дней действует скидка и время запуска. В списке видно, сколько отправлено, сколько купили и на какую сумму.

Скидка из уведомления или кампании — **персональная**: применяется у клиента сама и сгорает после покупки или по сроку. Со скидкой распродажи она не складывается — действует большая. Промокод тоже не складывается с ними: клиент платит меньшую из цен. Цены со скидкой округляются до целых рублей (в USD, EUR, GBP — до центов) и никогда вверх.

## Реферальная программа

Админка → «Рефералы». После установки программа выключена. Включите её и выберите, что получает пригласивший. У клиента в приложении появится «Пригласить друзей» со ссылкой `t.me/<бот>?start=r…`, кнопкой «Поделиться», списком друзей и статистикой.

**Дни подписки** — пригласившему +N дней, когда друг оплатит (за первую оплату или за каждую).

**Деньги** — процент с оплат друга (0–90%) на баланс пригласившего:
- **Вывод по заявке.** Способы вывода задаёте вы: банковская карта (номер проверяется контрольной суммой), СБП по номеру телефона, криптовалюта (адрес кошелька), любой свой. Клиент выбирает способ, вводит реквизиты и сумму; сумма сразу списывается с баланса, поэтому вывести одни деньги дважды нельзя. Заявка приходит админам в Telegram с кнопками «Выплачено» / «Отклонить» и видна в панели. Деньги переводите вы сами; отклонённая или отменённая клиентом заявка возвращает деньги на баланс, клиент получает уведомление.
- **Минимум для вывода** — по желанию.
- **Оплата подписки с баланса** — можно включить: баланс появится среди способов оплаты. С заказов, оплаченных балансом, процент не начисляется.
- Если программу выключить, заработанное остаётся у клиентов: его можно вывести или потратить.

В обоих режимах: другу — +N дней к первой покупке; **капча** для новых рефералов (бот просит нажать нужное число, пока не нажмёт — реферал не засчитывается); **топ рефоводов** за всё время, месяц или неделю — по бонусам, по оплатившим друзьям или по приглашённым, от 3 до 50 мест. Клиентам видны только первые 3 символа имени, в панели — полностью.

## Документы

Админка → «Документы». После установки документов нет — их проверяют платёжные системы и банки, поэтому это обязательный шаг во вкладке «Запуск».

- **Пользовательское соглашение** и **политика конфиденциальности** — на русском и английском. «Вставить шаблон» подставит готовый текст — поправьте под себя и сохраните. Шаблон — не юридическая консультация.
- Разметка простая: `# Заголовок`, `- пункт`, `**жирный**`, пустая строка — новый абзац. `{brand}`, `{owner}`, `{contact}` подставляются сами.
- **Продавец и контакты**: ФИО или название и статус, почта, контакт поддержки.
- **Частые вопросы** для раздела «Помощь» — редактор вопросов и ответов, есть готовый набор. Пока своих нет, показываются стандартные (как подключиться, устройства, телевизор).
- **О сервисе** — пара строк в «Помощи» и на публичной странице.

На публичной странице (`/` и `/legal`) показываются только написанные документы; в приложении ссылка на них появляется, когда они есть.

## Обязательная подписка на канал

Каналов может быть несколько (до пяти): «Добавить канал» — и человек должен подписаться на каждый; в мини-приложении для каждого своя кнопка «Подписаться». Админка → «Настройки» → «Обязательная подписка на канал»: укажите `@username` канала (или ID `-100…` и ссылку-приглашение для приватного) и режим — для всего сервиса или только для пробного периода. Бота нужно сделать администратором канала, иначе Telegram не покажет, кто подписан; кнопка «Сохранить и проверить» это проверит. Неподписанный клиент видит экран «Подпишитесь на канал» с кнопками «Подписаться» и «Я подписался». Если проверка в Telegram сломалась (бота убрали из канала), клиентов пропускает, а не блокирует.

## Настройки в админке

Всё, что меняется без перезапуска: пробный период (в «Тарифах»), название сервиса, текст приветствия, цена дополнительного устройства и максимум устройств, пакеты трафика, курс Stars, обязательный HWID, передача лимита устройств в панель как `limitIp`, период обновления подписки, кому показывать вход в админку, отзывы и подарки. Поддержка, документы, FAQ и данные продавца — во вкладке «Документы».

## Итоги дня и выгрузка в Excel

**Итоги дня.** Каждый день в выбранный час (по умолчанию 18:00 по времени сервера — это 21:00 по Москве, если сервер в UTC) владельцам приходит короткий отчёт в Telegram: выручка и покупки за сутки со сравнением со вчера, сколько человек заплатили впервые, новые люди и пробные, активные подписки, сколько закончится в ближайшие сутки, брошенные оплаты и что требует внимания (не отвечающие серверы, вопросы в поддержке без ответа, оплаченные, но не выданные заказы). Админка → «Настройки» → «Итоги дня в Telegram»: включить или выключить, час, «Прислать сейчас».

**Excel.** В «Заказах» кнопка **Excel**: заказы за период (этот месяц, прошлый, 30 дней, с начала года, всё время или свои даты) — дата, клиент, что куплено, тариф, сумма, способ оплаты, промокод, внизу итог. Удобно для учёта и «Мой налог». В «Пользователях» кнопка **Excel** выгружает клиентов: когда пришёл, откуда, тариф, до какого числа подписка, сколько купил и заплатил. Это настоящие таблицы .xlsx: числа складываются, даты сортируются, на заголовке фильтр. Если панель открыта в Telegram, файл приходит в чат с ботом.

## Резервные копии

Каждый день в выбранный час (по умолчанию 4:00 по времени сервера) сервис собирает архив и присылает его админам из `ADMIN_TELEGRAM_IDS` в Telegram. На сервере хранятся последние 7 — в `data/backups`. В админке → «Настройки» → «Резервные копии»: включить или выключить, час, «Сделать и прислать сейчас», скачать любой из сохранённых. В боте: `/backup`.

В архиве: вся база в переносимом виде (`db.json`, восстанавливается и в SQLite, и в PostgreSQL), копия файла SQLite и логотип. В нём есть всё, включая пароли панелей, — поэтому он уходит только админам.

Восстановить на новом сервере: поставьте сервис скриптом, затем

```bash
sudo vpn-seller restore /путь/backup-….zip
```

## Обновление

Магазин сам следит за новыми версиями. Раз в 6 часов он смотрит файл `VERSION` в репозитории на GitHub (том, что вписан в `install.sh`, или `UPDATE_REPO` в `.env`). Если вышла версия новее, владельцам приходит сообщение в Telegram — что нового и кнопка **«Обновить сейчас»**. То же — в админке → **«Обновления»** (на главной появляется строка «Вышла версия…»).

Как идёт обновление (кнопкой или командой `sudo vpn-seller update` — одно и то же):

1. копия базы в `data/backups`;
2. новый код: `git pull`, а если магазин ставился не из git — архив репозитория с GitHub (`.env`, `data/` и настройки прокси не трогаются);
3. пересборка и перезапуск;
4. проверка, что магазин отвечает. **Не отвечает — прежний код возвращается сам**, магазин снова работает, владельцам приходит сообщение с причиной.

После обновления приходит «✅ Магазин обновлён до X» со списком изменений; он же один раз показывается в админке. Можно включить **автообновление ночью** в выбранный час — одна попытка на версию.

Кнопку «Обновить» обслуживает systemd-юнит `vpn-seller-update.path`: магазин оставляет файл-задание в `data/`, юнит запускает обновление на сервере. Его ставит установщик (и любое `vpn-seller update`). Без systemd кнопка не работает — обновляйте командой.

Для закрытого репозитория впишите в `.env` токен GitHub с правом чтения: `GITHUB_TOKEN=…`. Новая версия выпускается так: поднимите номер в `VERSION`, допишите раздел в `CHANGELOG.md` (и `CHANGELOG.en.md`) и отправьте код — `bash scripts/publish-github.sh`.

Вручную без меню: `git pull && docker compose up -d --build`. Новые колонки в базе добавляются автоматически при старте.

База по умолчанию — SQLite, её хватает на тысячи клиентов. Для PostgreSQL раскомментируйте сервис `db` в `docker-compose.yml` и задайте `DATABASE_URL` в `.env`.

## Без Docker

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
set -a && . ./.env && set +a
uvicorn app.main:app --host 127.0.0.1 --port 8000 --proxy-headers
```

Перед сервисом нужен HTTPS-прокси (nginx, Caddy): Telegram открывает Mini App и шлёт вебхуки только по HTTPS.

## Разработка

```bash
pip install -r requirements-dev.txt

# настоящие панели 3x-ui 3.x и 2.x и Marzban локально (Linux x86_64)
scripts/dev-3xui.sh
scripts/dev-marzban.sh
source .dev/env.sh

python -m pytest              # юнит- и интеграционные тесты; без панелей часть пропускается
                              # Remnawave проверяется на заглушке tests/fake_remnawave.py, с настоящей
                              # панелью — REMNAWAVE_TEST_URL, REMNAWAVE_TEST_TOKEN, REMNAWAVE_TEST_SQUAD
TEST_DATABASE_URL=postgresql+psycopg://user:pass@localhost/test python -m pytest   # то же на PostgreSQL
python tests/e2e/e2e.py       # браузерный прогон приложения и админки (Playwright)
python tests/installer/run.py # установщик целиком: чистый сервер, curl | bash, чужой Caddy,
                              # nginx, туннель, меню, оплата, удаление + покупка на настоящей 3x-ui
```

**Автопроверка на GitHub** (`.github/workflows/tests.yml`): при каждой заливке GitHub сам поднимает настоящие панели 3x-ui 3.x и 2.x и Marzban, гоняет все тесты и все сценарии установщика (включая покупку на настоящей 3x-ui). Результат — значок вверху этого файла: зелёный — можно обновлять серверы, красный — сначала разобраться.

Прогон установщика не качает образы: вместо `docker` подставляется заглушка, которая проверяет compose-файлы настоящим `docker compose config`, запускает магазин через uvicorn и проверяет чужой Caddyfile настоящим `caddy validate`.

`PAYMENTS_TEST_MODE=true` делает все заказы бесплатными — удобно для проверки выдачи ключей. На рабочем сервере не включайте: админка покажет предупреждение.
