# VPN Seller Node — свой VPN-сервер без 3x-ui

VPN Seller Node — это маленькая программа (агент) на VPN-сервере. Она сама управляет Xray: добавляет и убирает клиентов, считает трафик, отключает тех, у кого кончился срок или гигабайты. Магазин даёт ей команды через защищённое соединение.

## Как добавить сервер

1. Купите сервер с Ubuntu 22/24 или Debian 12 (подойдёт 1 CPU / 1 ГБ).
2. В админке: **Серверы → Добавить сервер → «Свой сервер»**. Скопируйте команду из окна.
3. Зайдите на сервер по SSH и вставьте команду. Через 1–3 минуты она напечатает строку `vsnode://…`.
4. Вставьте эту строку в поле «Строка подключения», нажмите «Проверить», потом «Сохранить».

Строка `vsnode://…` — это ключ от сервера. Никому её не пересылайте.
Показать её ещё раз: `python3 /opt/vpn-seller-node/agent.py connect`.

## Что ставится

- Xray (официальный установщик XTLS) и два входа:
  - **VLESS Reality XHTTP**, порт 8443. Рекомендуется: в 2026 году его режут реже.
  - **VLESS Reality TCP (Vision)**, порт 443.
- BBR и сетевые буферы для скорости.
- Починка DNS, если на сервере он не работает.
- Агент `vpn-seller-node` (systemd). Его порт выбирается случайно.

Повторный запуск команды обновляет агента и сохраняет ключи и клиентов.

## Кнопка «Узел»

- **SNI** — чужой сайт, под который маскируется сервер. За границей подойдут `dl.google.com` или `www.microsoft.com`. Для моста в России берите сайт из белого списка, например `ya.ru` или `vk.com`. Готовые списки есть в репозитории igareck/vpn-configs-for-russia (WHITE-SNI-RU).
- **Порты** и включение/выключение входов XHTTP и TCP.
- **Новые ключи** — новые ключи Reality.
- **Перезапустить**.

После изменений ключи клиентов меняются. По подписке они обновятся сами. Ключи, скопированные вручную, придётся взять заново.

## Состояние и обновление

В окне «Узел» видно процессор, память, диск и трафик сервера. Если в магазине есть агент новее, появится кнопка «Обновить». Обновление идёт несколько секунд, клиентов не отключает.

Если Xray перестал отвечать, агент сам перезапустит его через пару минут.

## Из чата с ботом

`/servers` → кнопка ⚙ у своего сервера. Там видно состояние сервера, можно перезапустить Xray, обновить агент и включить или выключить цепочку.

## Цепочка (обход белых списков)

```
телефон ──► мост в России (IP в белом списке) ──► выходной сервер за границей ──► интернет
```

1. Поставьте VPN Seller Node на заграничный сервер, это выход.
2. Поставьте VPN Seller Node на российский сервер, это мост. Нужен хостинг, чьи IP проходят белые списки операторов. Проверить IP можно по WHITE-CIDR-RU.
3. Откройте «Узел» у моста и в разделе «Цепочка» выберите выходной сервер. Нажмите «Применить».
4. У моста включите «Обход белых списков» в настройках сервера, если продаёте такой трафик по гигабайтам.

Российские сайты мост открывает сам, напрямую. Это можно выключить.

## Перевод сервера с 3x-ui

```
curl -fsSL https://ВАШ-МАГАЗИН/scripts/node.sh -o node.sh && sudo bash node.sh --shop https://ВАШ-МАГАЗИН --takeover
```

`--takeover` останавливает 3x-ui. Дальше:

1. Удалите в магазине старый сервер с 3x-ui.
2. Добавьте этот же сервер как VPN Seller Node.
3. Нажмите «Залить клиентов».

Подписки клиентов останутся прежними, ключи внутри обновятся сами.

## Если что-то не работает

```
systemctl status xray vpn-seller-node
journalctl -u vpn-seller-node -n 50
journalctl -u xray -n 50
```
